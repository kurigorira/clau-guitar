# 🎸 clau-guitar

アコースティックギター用の **楽譜ライブラリ ＆ オリジナル譜面エディタ**。
個人利用を前提に、**データはすべて自分のPCの中だけ**に保存します（どこにもアップロードしません）。
スマホからは同じWi‑Fiで同じアプリを開けるので、PCとスマホで同じライブラリを見られます。

## できること

- **楽譜ライブラリ** — 曲名・アーティスト・タグ・キー・カポで整理／検索
- **PDF・画像の取り込み** — Yamahaで購入したPDFや、U‑FRET画面のスクリーンショットをアップして閲覧・メモ
- **コード譜エディタ** — 歌詞の上にコードを配置。押さえ方（コードダイアグラム）を自動表示。リアルタイムプレビュー付き
- **移調（トランスポーズ）＆カポ換算** — ±半音でキーを移調表示。カポ位置を指定すると「実際に鳴る音（コード名）」と「カポを付けて押さえる形（ダイアグラム）」を同時に表示
- **TAB譜エディタ** — 等幅表示のタブ譜を作成
- **練習記録** — 曲・日付・練習時間・できばえ（★）・メモを記録。直近7日／累計時間などの集計も表示
- **セットリスト** — 弾きたい曲・ライブや練習の曲順をまとめる。並べ替え・印刷対応
- **コード辞典** — 収録コードの押さえ方一覧
- **印刷対応** — 譜面・セットリストを紙に印刷（ブラウザの印刷機能）
- **バックアップ書き出し** — 全データ（楽譜・練習記録・セットリスト）をJSONでダウンロード

## 使い方

### 1. 準備（最初の一回だけ）

[Node.js](https://nodejs.org/)（v18以上）をインストールしてから:

```bash
npm install
```

### 2. 起動

```bash
npm start
```

起動すると次のように表示されます:

```
🎸 clau-guitar が起動しました
  このPC:      http://localhost:5173
  スマホから:  http://<このPCのIPアドレス>:5173  （同じWi‑Fiに接続）
```

- **PCで見る**: ブラウザで <http://localhost:5173> を開く
- **スマホで見る**: PCと同じWi‑Fiにつないで、`http://<PCのIPアドレス>:5173` を開く
  （PCのIPアドレスは Mac: システム設定→ネットワーク、Windows: `ipconfig` で確認できます。例: `http://192.168.1.10:5173`）
- スマホのブラウザで「ホーム画面に追加」すると、アプリのように使えます（PWA対応）。

> ⚠️ スマホから見るには、この起動しているPCが同じWi‑Fiで動いている必要があります。
> 外出先からも使いたい場合は、Render / Fly.io などにデプロイすれば同じアプリがそのまま動きます（その場合はアクセス制限の設定を推奨）。

## データの保存場所とバックアップ

- 保存先: プロジェクト内の `data/` フォルダ
  - `data/scores/` … オリジナルのコード譜・TAB譜（1曲＝1つのJSONファイル）
  - `data/documents/` … 取り込んだPDF/画像の情報
  - `data/uploads/` … PDF/画像の実ファイル
  - `data/practice/` … 練習記録
  - `data/setlists/` … セットリスト
- **バックアップは `data/` フォルダをまるごとコピーするだけ**。人が読めるJSON形式です。
- アプリ内の「バックアップ」メニューからメタデータをJSONで書き出すこともできます。

## コード譜の書き方（ChordPro風）

```
{title: 曲名}
{key: G}
{capo: 2}

{c: Aメロ}
[G]歌詞の上に[D]コードが乗ります
[Em]角カッコで[C]コードを囲む
```

- `{c: 見出し}` … セクション名（Aメロ・サビなど）
- `{define: Cadd9 base:1 frets:x,3,2,0,3,0}` … オリジナルの押さえ方を定義（弦は6弦→1弦、`x`=ミュート、`0`=開放）
- `#` で始まる行はメモ扱い（表示されません）

## TAB譜の書き方

6行で1弦〜6弦を表し、数字＝フレット、`-`＝休み、`|`＝小節線:

```
e|-----------------|
B|-----------------|
G|-----0-----------|
D|---2---2---0-----|
A|-3-------3-------|
E|-----------------|
```

## 著作権について

このアプリは購入したPDFや契約サービスのスクリーンショットを **自分ひとりが手元で管理・参照** するためのツールです。
取り込んだデータは外部に送信されず、あなたのPC内にのみ保存されます。
配布・共有・再アップロードは各コンテンツの利用規約・著作権法に従ってください。

## 技術構成

- バックエンド: Node.js + Express（依存は `express` と `multer` のみ、ネイティブビルド不要）
- データストア: JSONファイル（DB不要・バックアップ容易）
- フロントエンド: バニラJavaScript（ビルド不要）＋ PWA（オフライン対応）
